# Minik Diş — Çocuk Diş Kliniği

Pastel renkler, yumuşak mikro animasyonlar ve çocuk dostu bir randevu akışıyla hazırlanmış pedodonti kliniği ana sayfası.

## Teknoloji

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react

## Geliştirme

```bash
npm install
npm run dev
```

Üretim derlemesini doğrulamak için:

```bash
npm run typecheck
npm run build
```

## Notlar

Randevu formu bu demoda tarayıcı içinde etkileşimli bir önizlemedir; verileri herhangi bir servise göndermez. Ekip, iletişim ve çalışma saati bilgileri örnek içeriktir. Yayına almadan önce gerçek klinik bilgileri, gizlilik metinleri ve çalışan bir randevu/iletişim altyapısıyla güncellenmelidir.
